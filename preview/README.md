# Mobile interaction preview

Run `npm run ui:preview` with the project's Node 20 runtime. Open
http://127.0.0.1:4188. The server binds to loopback only.

This is a development fixture for the actual shared React Native components,
rendered through React Native Web. It does not import auth, SQLite, sync or API
clients. Its actions change fixture state only. It is not the installer app or
an end-to-end acceptance test. No preview route is added to the Android app.

The Vite configuration resolves Expo's `.web` implementations and its JSX/Flow
dependencies. It does not change Metro or the native build configuration.
