# Mobile interaction preview

Run `npm run ui:preview` with the project's Node 20 runtime. Open
http://127.0.0.1:4188. The server binds to loopback only.

This is a development fixture for the actual shared React Native components,
rendered through React Native Web. It does not import auth, SQLite, sync or API
clients. Its actions change fixture state only. It is not the installer app or
an end-to-end acceptance test. No preview route is added to the Android app.

The Vite configuration resolves Expo's `.web` implementations and its JSX/Flow
dependencies. It does not change Metro or the native build configuration.

## September 26 verification

- Common press feedback used by every existing mobile Pressable control.
- Disabled/busy actions do not execute; cancelled presses do not execute.
- Reduced-motion preference is observed through one app-wide subscription.
- Confirmation backdrop and Android back cannot dismiss an in-flight operation.
- Existing custom styles, transforms, native refs and Expo Link targets preserved.
- Cyrillic headings use Manrope instead of missing Sora glyphs; Hebrew uses the
  native system sans-serif family with explicit weight.
- Shared components checked in EN/RU/HE, including RTL, at measured browser CSS
  widths of 322 and 393 px. No horizontal page overflow; image asset loaded.
- Fixture workflow: open position, confirm completion, see updated count and
  disabled completion action; modal overlay removed after closing.

Automated checks: `npm run test`, `npm run typecheck`, and
`npm run test:coverage-contract`. Component tests mock native primitives;
native-device performance, gestures and screen-reader focus remain device checks.
Final run: 423 tests across 33 files, including 19 UI/workflow tests. The mobile
quality gate and Android export passed; temporary export output was removed.

Native export check (not an APK or production release):

Remove that temporary output after verification. No APK is generated by the UI preview.
